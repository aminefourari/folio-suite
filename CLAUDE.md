# Folio

pnpm monorepo of three TanStack Start apps plus a landing page, each deployed as its own Cloudflare Worker
(workers.dev). Files are stored in one shared Cloudflare D1 database (SQLite) named `folio`.

Product names are deliberately original (Folio Write / Grid / Stage). Never use Microsoft (Word, Excel,
PowerPoint, Office) or Google (Docs, Sheets, Slides) product names or look-alike branding.

## Commands (run from the repo root)
- `pnpm dev`: all apps in parallel: landing :3000, write :3001, grid :3002, stage :3003. Each app has its own local D1 under `apps/<app>/.wrangler/`.
- `pnpm --filter @folio/write dev`: a single app
- `pnpm typecheck`: `tsc --noEmit` per app (route trees are generated by `dev`/`build`)
- `pnpm test`: `node --test` over `apps/grid/src/formula.test.ts` (formula engine and CSV)
- `pnpm build`: `vite build` per app
- `pnpm run deploy`: `vite build && wrangler deploy` per app. Plain `pnpm deploy` is a pnpm built-in, not this script.

## Structure
- `packages/ui/src/` (imported as `@folio/ui/<file>` with the extension):
  - `apps.tsx`: app registry (names, colours, ports, workers.dev URLs via `urlFor`), Google Fonts URL, `DOC_FONTS`, favicons
  - `root.tsx`: shared `<head>` and HTML shell. `styles.css`: design tokens and shared components.
  - `Select.tsx`: custom ARIA listbox select. Don't use native `<select>`.
  - `autosave.tsx`: `useAutosave(persist)` and `SaveBadge`
  - `chrome.tsx`: `SuiteNav`, `FileHome` (files grid), `EditorBar`, `Tool`/`WideTool` toolbar buttons
  - `server.ts`: D1 storage, schema created lazily, everything scoped by the anonymous `folio_owner` cookie. Server only: import it only inside `createServerFn` handlers.
  - `cloudflare.d.ts`: minimal D1 and `cloudflare:workers` types (the full workers-types package clashes with DOM types)
  - `util.ts`: `sanitize` (browser only), CSV/download helpers, relative time
- `apps/<app>/src/docs.ts`: thin `createServerFn` wrappers around `server.ts` (the compiler needs them at top level in app code)
- `apps/<app>/src/routes/`: `index.tsx` (files grid) and `doc.$id.tsx` (editor). `routeTree.gen.ts` is generated; commit it, never edit it.
- `apps/<app>/wrangler.jsonc`: Worker name and D1 binding `DB`

## Conventions
- Each app sets its accent with `:root { --app: … }` at the top of its `app.css`; keep it in sync with `APPS`.
- Toolbar components must be module-level (`Tool`, `Select`). Components defined inside an editor function remount on every keystroke.
- HTML from the DB or imports goes through `sanitize()` before it touches the DOM. That needs `DOMParser`, so server-rendered previews use `plainText`/`escapeHtml` instead.
- Grid content is JSON with cells in row-major key order, and Stage puts `theme` first, so the 4 KB `preview` prefix the list returns covers the top-left of a sheet or the first slide.
- Limits live in `server.ts`: 1.5 MB per file and 200 files per visitor per app.
